# tiktok
Автоматична нарізка вертикальних відео з довгих YouTube-роликів

Локальний конвеєр на Python, який сам знаходить нові відео на YouTube-каналах, шукає в них найцікавіші моменти за допомогою ШІ та монтує готові вертикальні клипи (9:16) із субтитрами і рекламним банером. Усе працює на власному ПК, без платних API і підписок.

Проєкт створено в навчальних цілях як практика автоматизації з ШІ. Код писався разом із ШІ-асистентом, а я налагоджував, тестував і підлаштовував його під свою задачу.

Як це працює
channels.txt ──► 1_downloader.py ──► 2_analyzer.py ──► 3_editor.py ──► ready/
 (канали)        RSS + yt-dlp        Whisper + LLM      FFmpeg          клип.mp4
                 history.json        analysis/*.json                    клип.txt
Пошук і завантаження (1_downloader.py). Читає список каналів, перевіряє нові відео через безкоштовні RSS-стрічки YouTube, пропускає занадто короткі та довгі, качає відео через yt-dlp. ID вже завантажених відео записує в history.json, тому одне відео ніколи не качається двічі.
Аналіз (2_analyzer.py). Розпізнає мову за допомогою faster-whisper на відеокарті (з таймкодами кожного слова). Транскрипт ділить на шматки й віддає локальній мовній моделі через Ollama (qwen2.5:7b). Модель повертає JSON із найкращими моментами: початок, кінець, заголовок, хештеги, оцінка. Код перевіряє відповідь: тривалість, перекриття, межі речень.
Монтаж (3_editor.py). За допомогою FFmpeg з апаратним прискоренням NVIDIA (h264_nvenc) робить вертикальне відео 1080x1920 із розмитим фоном, динамічними субтитрами з підсвічуванням слів (формат .ass), легкою корекцією кольору й швидкості та вставкою банера на хромакеї (на 15-й секунді відео зупиняється, грає банер зі своїм звуком, потім відео продовжується).
Що використано
Python 3.11
yt-dlp, requests: завантаження
faster-whisper (модель large-v3-turbo, CUDA): розпізнавання мови
Ollama + qwen2.5:7b: пошук цікавих моментів
FFmpeg (h264_nvenc, chromakey, libass): монтаж
Вимоги
Windows 10/11
Відеокарта NVIDIA (тестувалось на RTX 4060, 8 ГБ)
Python 3.11 (новіші версії можуть не підійти для окремих бібліотек)
FFmpeg і Ollama, встановлені в системі
Встановлення
bat
cd /d C:\tiktok_bot
py -3.11 -m venv venv
venv\Scripts\activate
pip install yt-dlp faster-whisper ollama playwright requests
pip install nvidia-cublas-cu12 "nvidia-cudnn-cu12==9.*"
ollama pull qwen2.5:7b

Шляхи до папок задані на початку кожного скрипта (змінна BASE_DIR). За потреби змініть їх.

Запуск
Додайте посилання на канали у файл channels.txt (по одному в рядок).
За бажанням покладіть відео-банер на зеленому фоні як banner.mp4.
Двічі клацніть run_all.bat або запустіть по черзі:
bat
python 1_downloader.py
python 2_analyzer.py
python 3_editor.py

Готові клипи й текстові файли з описом з'являться в папці ready.

Налаштування

На початку кожного скрипта є блок НАЛАШТУВАННЯ: розмір субтитрів, швидкість, колір і положення банера, мінімальна й максимальна тривалість клипа, кількість клипів із одного відео, модель розпізнавання тощо.

Обмеження
Якість пошуку моментів залежить від невеликої локальної моделі (7B): вона знаходить цікаве, але слабо ранжує. Заголовки та хештеги варто перевіряти вручну.
Потрібна відеокарта NVIDIA. Без неї монтаж піде на процесорі, а розпізнавання треба переналаштувати.
Використовуйте лише власні відео або відео, на які маєте дозвіл автора чи відкриту ліцензію. Нарізка чужого контенту без дозволу може порушувати авторські права.
